Privacy Policy for Moje Rozliczenia

Last updated: September 23, 2026

This Privacy Policy describes how the Moje Rozliczenia application processes user information. The application is designed to record expenses, split costs, settle trips, and plan related tasks.

1. Data controller

The data controller for information related to the Moje Rozliczenia application is the application developer.

Privacy contact: janmichalak78@gmail.com

2. Data the application may process

  • expense names, descriptions, amounts, currencies, dates, and categories;
  • information about trips, events, participants, and cost sharing;
  • information about repayments, refunds, and settlements between participants;
  • receipt photos taken with the camera or selected from the gallery;
  • data extracted from receipts, such as the merchant, date, amount, and items;
  • packing lists, events, and reminders;
  • technical data needed to operate the application, such as the app version and basic device information;
  • data needed for synchronisation, if the user uses this feature.

3. Camera and receipt photos

The application may use the camera to let the user take a photo of a receipt. The user may also select an image from the gallery or the system file picker. Images are used to extract receipt information and prepare an expense for review.

Before saving an expense, the user can edit or reject the information recognised from the image. Temporary photos created for processing may be deleted after processing is complete.

4. Artificial intelligence

The application may use artificial intelligence models to suggest expense categories and analyse receipt data. Models may run locally on the user's device. The user may also import compatible models into the application's storage.

AI results are provided as assistance and may contain errors. Users should check the information before saving an expense.

5. Synchronisation and network services

If the user enables synchronisation, data required to synchronise trips, participants, expenses, and settlements may be sent to the network services used by the application. Synchronisation is used to provide access to data on supported devices and to exchange data between trip participants.

If the user does not use synchronisation, locally stored data remains on the device, except for features that the user explicitly starts.

6. Purpose of processing

Data is used to record expenses, calculate cost shares, calculate repayments, create summaries, manage trips and events, process receipts, synchronise data, and send reminders selected by the user.

7. Sharing of data

Data may be shared only with technical service providers needed to operate the application and synchronisation, to the extent necessary to provide the selected feature. Data is not sold or used for behavioural advertising.

8. Data retention and deletion

Data is retained for as long as necessary to operate the application or fulfil the purpose for which it was collected. Users may delete expenses, trips, and other data directly in the application where the relevant feature is available. Users may also request deletion of their data by contacting the address provided in this policy.

9. Security

Reasonable technical and organisational measures are used to protect data against unauthorised access, loss, or misuse. However, no method of transmission or storage can guarantee complete security.

10. Notifications

With the user's permission, the application may send local notifications about planned events, trips, tasks, and reminders. Users can disable notifications in their device settings.

11. Changes to this Privacy Policy

This Privacy Policy may be updated from time to time. The current version will be published on this page together with the date of the latest update.
